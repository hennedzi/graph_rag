## Цель
Финальный текст ответа стримится токенами в ленту Harness через тот же SSE-канал C1.
Первые токены < 2 с на быстром пути C4.

## Контекст: где это в коде
- `harness.py` — финальная генерация ответа; сейчас вызов LLM возвращает текст целиком.
- `api.py` — SSE-поток из C1; добавить новый тип события.
- `web/src/pages/Harness` — рендер ответа; сейчас ждёт завершения.

## Что сделать
1. В `harness.py` включи стрим у провайдера LLM (streaming API) и передавай чанки в `emit`.
2. Новое событие: `{"type": "token", "seq": ..., "text": "..."}` — то же поле `seq`, тот же канал.
3. Финал: событие `answer_finished` с полным текстом и `citations` из C6 (если C6 уже сделан).
4. В `web/src` накапливай токены в сообщении ответа, рендерь инкрементально; маркеры цитат
   из C6 подключай на `answer_finished`.
5. Тест: трасса содержит хотя бы два события `token` перед `answer_finished`.

## Границы задачи
- Не стримь промежуточные рассуждения агента — только финальный ответ.
- Не ломай запись полного ответа в `runs/` — стрим только для UI.
- Если C6 ещё не сделан — цитаты не подключай, отдельная связка.
