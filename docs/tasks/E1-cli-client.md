## Цель
Работать с базой не только через веб-интерфейс, но и из терминала: полноэкранный клиент
со стримингом ответа, историей диалога и hotkeys, плюс построчный REPL как fallback для pipes.

## Контекст: где это в коде
- `cli.py` — новый файл: `TUI` (curses) + `repl()`; общие helpers `iter_sse`, `request`, `print_result`.
- `api.py` — `POST /harness/stream` (SSE: `start`, `thought`, `call`, `result`, `token`, `done`, `error`).
- `config.ini` — `url` LLM; клиент ходит только в API, модели не знает.

## Что сделать
1. Создай `cli.py` (старый код не трогай): клиент к `http://127.0.0.1:8200`, адрес через `--url` / `RAG_URL`.
2. `TUI`: статус-бар, лента диалога, строка ввода, подсказка хоткеев; стриминг `token` с троттлингом отрисовки.
3. Хоткеи: `F1` справка, `F2` новая сессия, `F3` runs, `F4` документ, `F5` стрим, `F10` выход, `PgUp/PgDn`.
4. `session_id` из `done` прокидывай в следующий вопрос; `Ctrl+C` — `/harness/stop`.
5. Fallback: если stdout не TTY или `--no-tui` — построчный REPL; при падении curses — автоматически в REPL.
6. Один вопрос без REPL: `uv run cli.py "вопрос"`.

## Границы задачи
- Не менять `api.py`/`harness.py` и формат событий — клиент только потребитель SSE.
- Не добавлять зависимости: только stdlib (`curses`, `urllib`).
- Не коммитить `config.ini`, `runs/`, кэши.

## Как проверить
```
uv run pytest -q test_cli.py
uv run cli.py --no-tui -q "Кто был учителем Эйлера?"
uv run cli.py            # в TTY: F1, F3, F4, F10
```
