## Цель
Кэш с TTL для эмбеддингов вопросов и результатов гибридного поиска. Повторные и близкие вопросы
отвечают мгновенно, префетч C3 пользуется тем же кэшем.

## Контекст: где это в коде
- `core.py` — функции `embedding(question)` и гибридного поиска; кэш — прозрачный слой вокруг них.

## Что сделать
1. В `core.py` заведи простой in-memory кэш (dict + таймстемпы, без внешних зависимостей):
   ключ — нормализованный текст вопроса (lowercase, strip) + область поиска.
2. Оберни `embedding` и `hybrid_search`: при попадании — вернуть копию результата и пометить
   событие `cache_hit: true`.
3. TTL по умолчанию 300 с, в конфигурации.
4. Инвалидация: при загрузке/удалении документа очищать записи, чья область поиска затронута
   (если области нет — очищать весь кэш, честно и просто).
5. Тест: два одинаковых запроса — второй из кэша; после инвалидации — снова полный.

## Границы задачи
- Не кэшируй ответы LLM — только эмбеддинги и результаты поиска.
- Не вводи Redis и внешние хранилища — in-memory достаточно.
- Кэшированный результат в трассе обязан иметь пометку.
