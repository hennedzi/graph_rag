## Цель

Ответ агента содержит чистый текст без markdown, а источники передаются отдельно в поле `sources` (список хэндлов `["P1", "P2"]`). В ответе API есть поле `citations` — словарь `handle → {doc_id, doc, text}`. Клик по источнику в UI открывает пассаж и подсвечивает его. Это даёт прозрачность: переход «утверждение в ответе → фрагмент документа».

## Контекст: где это в коде

- `harness/render.py` — `render()`: принимает `text` и `sources`, валидирует хэндлы, возвращает `(text, claims, errors, sources)`
- `harness/__init__.py` — `answer` tool вызывает `render()`, затем `citations(st, answer, sources)` для SSE и финального ответа
- `core.py` — `verify()`: проверяет утверждения по переданным источникам
- `web/src/components/answer-card.tsx` — `ProseAnswer` (рендерит текст, делает кликабельными `[P#]` если есть) + `SourcesList` (список всех источников снизу)

## Что сделано

1. **Новый формат ответа**: `answer(text="...", sources=["P1", "P2"])` — текст без markdown, источники в отдельном массиве.
2. **Обратная совместимость**: если модель вернула текст с `[P#]` — тоже работает, хэндлы извлекаются автоматически.
3. **Валидация в render()**: проверяет что все хэндлы известны (`st["pid"]`) и прочитаны (`st["read"]`).
4. **Верификация**: `check(st, text, sources)` получает явный список источников, не парсит их из текста.
5. **SSE событие `answer_finished`**: передаёт `text` и `citations` (словарь хэндл → полный пассаж).
6. **Фронтенд**: `ProseAnswer` рендерит параграфы, `SourcesList` показывает все источники с превью текста.

## Критерии готовности

- [x] Источники передаются отдельно в JSON (`sources` в запросе, `citations` в ответе).
- [x] Текст ответа не требует инлайн-маркеров `[P#]` (но поддерживает их для совместимости).
- [x] Верификация использует явный список источников.
- [x] Фронтенд показывает список источников и текст пассажа при наведении/клике.
